# 🎲 Python Dice Roller

A simple **Python Dice Rolling Game** where the user can choose to roll two dice repeatedly until they decide to stop.

## 📌 About the Project

This project was created as a beginner Python project to practice:

* `while` loops
* `if / elif / else` conditions
* User input
* The `random` module
* `random.randint()`
* String methods like `.lower()` and `.strip()`
* F-strings
* Using `break` to exit a loop

## 🚀 How It Works

1. The program asks the user whether they want to roll the dice.
2. If the user enters `yes`, two dice are rolled.
3. Each die generates a random number between **1 and 6**.
4. The results of both dice are displayed.
5. The user can continue rolling as many times as they want.
6. If the user enters `no`, the game ends.

## 🛠️ Technologies Used

* Python 3
* Python `random` module

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/python-dice-roller.git
```

Navigate into the project folder:

```bash
cd python-dice-roller
```

Run the program:

```bash
python dice_roller.py
```
